# RARI OMEGA FINAL V2

V1 preflight did not launch science because the fixed 8 GiB disk reserve was too strict. V2 uses a bounded dynamic working-set calculation and, importantly, strengthens the nine-track real-bio branch: it searches retained V5 authoritative/staging/unit evidence and attempts the frozen scorer in an isolated bounded copy where available. It never downloads entire public datasets and never upgrades retrospective evidence into fresh prospective biological validation.

Old NeuroBrain V4/V7 locks and the GOP frozen core are immutable. No E2B/Kimi/provider calls are authorized.
